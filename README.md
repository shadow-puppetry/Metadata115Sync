# Metadata115Sync V2

MoviePilot V2 插件：只做 **本地 → 115** 的元数据单向补齐。

## 功能

- 不使用 TMDB
- 不刮削、不生成元数据
- 不上传视频/STRM
- 本地有、115没有 → 上传
- 115已有 → 跳过
- 不覆盖、不删除115文件
- 支持立即同步
- 支持扫描预览（不上传）
- 插件页面显示执行统计和最近日志
- 支持自动定时同步

## 推荐配置

如果本地 STRM 根目录是 `/strm`，115 的对应根目录是 `/影视库/媒体目录`：

```text
/strm=/影视库/媒体目录
```

相对路径保持不变。例如：

```text
/strm/电影/流浪地球/poster.jpg
```

对应：

```text
/影视库/媒体目录/电影/流浪地球/poster.jpg
```

## 第一次使用

1. 填写映射。
2. 保存。
3. 打开插件详情页。
4. 先点「扫描预览（不上传）」确认本地文件确实被发现。
5. 确认无误后点「立即同步」。
6. 在「最近执行日志」查看每个文件是上传、跳过还是失败。
