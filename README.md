# Metadata115Sync V2

MoviePilot V2 插件：只把本地媒体目录中的元数据文件单向同步到 MoviePilot 已配置的 115 存储。

## 核心策略

- 不使用 TMDB。
- 只同步配置的元数据扩展名，不上传视频文件。
- 本地文件缓存优先：文件大小、`mtime_ns` 未变化且远程检查缓存未过期时，直接跳过，不访问 115。
- 115 目录结果独立缓存，默认 6 小时；同一次任务中同一远程目录只查询一次。
- “扫描预览”生成可复用的同步计划；“立即同步”优先复用最近一次有效计划，避免重复扫描和重复查询。
- 上传并发默认 2，最高 3，避免集中轰击 115。
- 115 不存在的目标目录只在真正同步时创建，预览阶段不会创建目录。
- 不删除 115 文件，不修改本地文件，不上传视频。
- 状态和日志只使用 MoviePilot 自带机制。

## 映射

```text
/strm=/影视库/媒体目录
```

左侧是 MoviePilot 容器内的本地路径，右侧是 115 目标路径。
